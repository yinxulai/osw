# 上游代理

**上游代理**（出站代理）决定 OSW 用什么网络出口去访问上游。在**设置 → 网络 → 上游代理**里配置。

## 三种模式

| 模式 | 行为 |
| --- | --- |
| **直连** | 不经任何代理，直接访问上游。 |
| **跟随系统** | 用操作系统当前的代理设置。 |
| **自定义** | 手动填一个代理地址。 |

## 什么时候需要

- 上游只能通过公司代理访问。
- 需要把模型请求固定走某个出口。
- 本地网络对上游直连不稳定，走代理更稳。

## 哪些流量不走代理

<Callout title="统计流量不走你的代理" type="info">
匿名使用统计**永不走**用户配置的出站代理，它是独立直连的。这样代理日志里不会出现你没预期的目标，代理配错也不会让统计永久失败。见[本地优先与密钥](/privacy)。
</Callout>

## 与协议转换无关

上游代理只改**网络出口**，不改协议。请求的协议处理见[本服务支持的协议](/protocols)。

<Callout title="代理配错的表现" type="warning">
自定义代理地址填错会导致所有上游请求连不上，表现为请求记录里普遍出现网络错误。切回直连可快速确认是不是代理的问题。
</Callout>
