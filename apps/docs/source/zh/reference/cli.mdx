# 命令行

命令行形态与桌面端共用同一份数据目录与配置，适合无头环境、容器或脚本化运行。

<Callout title="命令行尚未发布" type="warning">
命令行形态**目前未发布，也未经过人工验收**：包未对外公开，「osw」也没有可供安装的分发渠道。下面写的是它**已经实现的能力**，现阶段只有从源码构建才能运行。日常使用请以**桌面端**为准。
</Callout>

## 用法

```bash
osw [命令] [选项]
```

| 命令 | 说明 |
| --- | --- |
| `start` | 启动服务（**不写命令时的默认行为**）。 |
| `stop` | 停止由本 CLI 启动的实例。 |
| `status` | 输出运行状态、监听地址、数据目录与版本。 |
| `user` | 管理登录账号：`list` / `add <用户名>` / `remove <用户名>`。 |
| `version` | 输出版本号。 |

## 选项

| 选项 | 说明 |
| --- | --- |
| `--data-dir` | 数据目录。 |
| `--host` | 代理监听地址。 |
| `--management-host` | 管理面监听地址。缺省跟随回环；填 `0.0.0.0` 就是把控制台开放给网络。 |
| `--proxy-port` | 代理端口。 |
| `--management-port` | 管理端口。 |
| `--password-stdin` | 从标准输入读口令（**仅 `user add`**）。 |
| `--web` | 由管理服务托管控制台（默认开启）。 |
| `--no-web` | 不托管控制台，只提供 HTTP API。 |
| `--json` | 以 JSON 输出（**仅 `status`**）。 |
| `--help` | 显示帮助。 |
| `--version` | 输出版本号。 |

<Callout title="管理面默认只监听本机" type="note">
管理面缺省只监听 `127.0.0.1`，且不要求登录——桌面与个人本机就该是这样。要在别的机器上打开控制台，用 `--management-host 0.0.0.0`：这时**默认要求账号登录**（非回环监听下默认开启「要求登录」）。
</Callout>

## 启动

启动后会打印控制台地址、代理地址、管理服务地址与数据目录，按 `Ctrl+C` 停止。

<Callout title="--host 会暴露无鉴权代理" type="warning">
代理监听在非回环地址上时，同网络的其它设备可以直接访问它，而它**不带鉴权**（代理侧不校验调用方身份，鉴权是管理面的事）。只想本机使用，就别传 `--host`（默认只监听 `127.0.0.1`）。
</Callout>

## 账号

把服务装到服务器上共享给多个人用时，先建一个账号：

```bash
osw user add admin            # 交互输入口令（不回显）
printf '%s' "$PASSWORD" | osw user add admin --password-stdin
osw user list
osw user remove admin
```

口令**不接受命令行参数**，只能交互输入或走 `--password-stdin`：命令行参数会留在 shell 历史与 `ps` 里。改口令在控制台的「访问控制」里做。

<Callout title="先有账号，才能监听非回环地址" type="warning">
`osw start --management-host 0.0.0.0` 在**没有任何账号**时会拒绝启动。这不是意外：非回环监听下「谁能连上端口」不再是边界，没有账号的服务一开，同网络的任何人都能读走全部密钥。`osw user` 不要求服务在跑——它直接写数据库，正是为这一步准备的。
</Callout>

## 状态

```bash
osw status          # 人类可读
osw status --json   # 供脚本消费
```

状态包含：运行中 / 未运行 / 无响应、管理服务、代理地址、控制台、数据目录、版本、PID、启动时间。

几种提示值得留意：

- **端口没在监听**：进程还在，但代理端口没有监听——服务可能启动到一半就失败了。
- **版本漂移**：运行中的实例版本与当前 CLI 版本不一致。

## 停止

`osw stop` 向实例发出退出请求并做清理。若没找到运行中的实例，会清理失效的运行时文件；若实例没开启退出握手（或那个端口上其实是别的服务），会拒绝退出请求。

## 冲突处理

- **端口被占用**：停掉占用进程，或用 `--proxy-port` / `--management-port` 换端口。
- **已有实例在运行**：先用 `osw stop` 停掉；要同时跑两个，给其中一个 `--data-dir` 指定另一个数据目录。

## 错误码与文案

命令行输出的错误是本地化的。代理运行期的错误码会在[请求记录](/observability/request-logs)中展示，含义见[常见问题](/reference/troubleshooting)。
