# 设置项

**设置**页管理应用行为、网络连接、故障恢复与本地数据，按六个分区组织：**应用 / 网络 / 路由 / 可靠性 / 数据 / 云同步**。改动保存后生效，底部会提示同步与保存状态。

## 应用

### 外观与启动

| 设置项 | 说明 |
| --- | --- |
| 主题 | 跟随系统 / 亮色 / 暗色。 |
| 语言 | 界面语言，日志与错误信息固定为英文。 |
| 开机自启 | 登录系统时自动启动并隐藏到托盘。 |

### 版本更新

检查更新、下载与安装。macOS 只能检查并打开 DMG 下载页；包含破坏性变更的大版本不支持自动更新，需手动下载。详见[安装与启动](/getting-started/installation)。

### 引导

可以**重新运行**首次启动的三步引导。

## 网络

### 监听服务

| 设置项 | 说明 |
| --- | --- |
| 监听地址 | 推荐 `127.0.0.1`，仅允许本机访问。 |
| 监听端口 | 默认 `9300`，保存后代理自动使用新端口。 |

### 上游代理

决定 OSW 访问模型服务时的网络路径：

| 模式 | 说明 |
| --- | --- |
| 不使用任何代理 | 所有上游请求强制直连。 |
| 使用系统代理 | 跟随操作系统的代理设置。 |
| 自定义代理 | 使用指定的 HTTP / HTTPS / SOCKS 代理。 |

自定义模式下可填**代理 URL**（凭据保存在本机，仅使用可信代理）与**直连地址**（逗号分隔，支持 `*.example.com` 与 `<local>`）。还可以**测试连接**：用当前配置请求一次轻量地址，验证代理是否可用。详见[上游代理](/upstreams/outbound-proxy)。

## 路由

### 路由模式

决定代理执行哪一份路由定义（工作流编排 / 路由规则）。**切换立即生效，不需要保存**。详见[请求选路](/upstreams/routing)。

## 可靠性

### 故障转移

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 连续失败阈值 | 3 次 | 达到后供应商进入冷却。 |
| 初始冷却 | 30 秒 | 首次进入冷却的等待时长。 |
| 最大冷却 | 5 分钟 | 冷却随失败次数递增，不超过该上限。 |
| 流式空闲超时 | 30 秒 | 流式响应在该时长内没有新数据即判失败。 |

详见[故障转移](/upstreams/failover)。

### 缓存亲和

| 设置项 | 说明 |
| --- | --- |
| 启用缓存亲和 | 首位供应商进入冷却时，会话留在继任供应商上；恢复的供应商靠**新会话**拿回流量，不再自动切回。 |
| 绑定保持 | 会话空闲超过该时长后绑定作废，按新会话调度。 |

详见[缓存亲和](/upstreams/cache-affinity)。

## 数据

### 数据目录

显示配置、数据库与凭据所在的目录，可**在文件管理器中打开**（只有桌面端可打开；命令行形态请按路径自行访问）。还显示本目录下观测数据库的**数据占用**，清理历史日志后会立即变小。详见[数据目录与保留](/observability/data)。

### 请求日志

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 记录请求日志 | 开 | 请求身份、逐次尝试的用量与指标。关闭后请求照常转发但不落库。 |
| 请求日志保留 | 永久 | 自动删除早于设定天数的请求日志（连同尝试、用量与正文）。 |
| 正文保留 | 7 天 | 自动删除早于设定天数的请求与响应正文；请求、尝试与指标保留。 |
| 记录请求与响应正文 | 开 | 便于排查问题，但日志中可能包含敏感信息。 |

还可以**清理历史日志**：按天数立即删除已有历史记录，不影响自动保留设置。

### 日志保留

运行日志的保留时长，与请求日志是**两套独立设置**。详见[运行日志](/observability/runtime-logs)。

## 云同步

选择同步方式、连接凭据、绑定远端位置，并手动**备份到云端**或**从云端恢复**。恢复会用远端快照整份覆盖本机的供应商、模型与绑定，覆盖后无法撤销；快照里没有的逻辑模型保持不动。详见[配置云同步](/observability/cloud-sync)。
