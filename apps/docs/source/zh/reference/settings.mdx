# 设置项

**设置**页管理应用行为、网络连接、故障恢复与本地数据，按七个分区组织：**应用 / 网络 / 路由 / 可靠性 / 数据 / 云同步 / 开发者**。改动保存后生效，底部会提示同步与保存状态。

![OSW「设置」页顶部：应用分区的外观与启动、实时指标、版本更新与重新运行引导。](/screenshots/zh-CN/light/settings-overview.png)

## 应用

### 外观与启动

| 设置项 | 说明 |
| --- | --- |
| 主题 | 跟随系统 / 亮色 / 暗色。 |
| 语言 | 界面语言，日志与错误信息固定为英文。 |
| 开机自启 | 登录系统时自动启动并隐藏到托盘。 |

### 实时指标

在**菜单栏**（仅 macOS）与应用**窗口标题栏**上显示一段由模板拼出的实时指标，默认开启。两个展示面共用同一份数与同一段模板，只是各自的显示开关分开。

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 在菜单栏显示 | 开 | 菜单栏图标右侧的一段文字。仅 macOS 有此能力。 |
| 在应用窗口显示 | 开 | 窗口标题栏「运行状态」左侧的同一份指标。 |
| 模板 | `{liveTps} TPS` | 普通文本与花括号变量；留空即用默认模板。最长 64 个字符。 |

可用变量：

| 变量 | 含义 |
| --- | --- |
| `{liveTps}` | 最近一次已知的输出速度（Token/秒）：有在途请求时是它的实时速度，没有时回落到最近一条已结束请求的速度（仅限落定后 5 秒内）。 |
| `{activeRequests}` | 此刻正在进行的请求数。 |

速度优先取**最近一个在途请求**（刚发出的那条），随请求进行实时收敛；上游通常要到收尾才报输出 Token，正文一旦开始流动就用其估算值先顶上，真实用量到达后覆盖。没有在途速度时，回落到内存里**最近一条已结束请求**的最终速度，但**只在这条请求落定后 5 秒内**——超过时限后旧值不再充数，如实回到 `--`。只有内存里一条算得出速度、且还在时限内的请求都没有，才显示 `--`（零也显示为 `--`）。

### 版本更新

检查更新、下载与安装。macOS 只能检查并打开 DMG 下载页；包含破坏性变更的大版本不支持自动更新，需手动下载。详见[安装与启动](/getting-started/installation)。

### 引导

可以**重新运行**首次启动的两步引导。

## 网络

### 监听服务

| 设置项 | 说明 |
| --- | --- |
| 监听地址 | 推荐 `127.0.0.1`，仅允许本机访问。 |
| 监听端口 | 默认 `9300`，保存后代理自动使用新端口。 |

### 上游代理

决定 OSW 访问模型服务时的网络路径：

| 模式 | 说明 |
| --- | --- |
| 不使用任何代理 | 所有上游请求强制直连。 |
| 使用系统代理 | 跟随操作系统的代理设置。 |
| 自定义代理 | 使用指定的 HTTP / HTTPS / SOCKS 代理。 |

自定义模式下可填**代理 URL**（凭据保存在本机，仅使用可信代理）与**直连地址**（逗号分隔，支持 `*.example.com` 与 `<local>`）。还可以**测试连接**：用当前配置请求一次轻量地址，验证代理是否可用。详见[上游代理](/upstreams/outbound-proxy)。

## 路由

### 路由模式

决定代理执行哪一份路由定义（工作流编排 / 路由规则）。**切换立即生效，不需要保存**。详见[请求选路](/upstreams/routing)。

![OSW「设置 → 路由 → 路由模式」卡片：在工作流编排与路由规则之间切换。](/screenshots/zh-CN/light/settings-route-mode.png)

## 可靠性

### 故障转移

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 连续失败阈值 | 3 次 | 达到后供应商进入冷却。 |
| 初始冷却 | 30 秒 | 首次进入冷却的等待时长。 |
| 最大冷却 | 5 分钟 | 冷却随失败次数递增，不超过该上限。 |
| 流式空闲超时 | 30 秒 | 流式响应在该时长内没有新数据即判失败。 |

详见[故障转移](/upstreams/failover)。

### 缓存亲和

| 设置项 | 说明 |
| --- | --- |
| 启用缓存亲和 | 首位供应商进入冷却时，会话留在继任供应商上；恢复的供应商靠**新会话**拿回流量，不再自动切回。 |
| 绑定保持 | 会话空闲超过该时长后绑定作废，按新会话调度。 |

详见[缓存亲和](/upstreams/cache-affinity)。

## 数据

### 数据目录

显示配置、数据库与凭据所在的目录，可**在文件管理器中打开**（只有桌面端可打开；命令行形态请按路径自行访问）。还显示本目录下观测数据库的**数据占用**，清理历史日志后会立即变小。详见[数据目录与保留](/observability/data)。

### 请求日志

![OSW「设置 → 数据 → 请求日志」卡片：记录开关、请求日志保留、正文保留、记录正文开关与清理历史日志。](/screenshots/zh-CN/light/settings-log-retention.png)

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 记录请求日志 | 开 | 请求身份、逐次尝试的用量与指标。关闭后请求照常转发但不落库。 |
| 请求日志保留 | 永久 | 自动删除早于设定天数的请求日志（连同尝试、用量与正文）。 |
| 正文保留 | 7 天 | 自动删除早于设定天数的请求与响应正文；请求、尝试与指标保留。 |
| 记录请求与响应正文 | 开 | 便于排查问题，但日志中可能包含敏感信息。 |

还可以**清理历史日志**：按天数立即删除已有历史记录，不影响自动保留设置。

### 日志保留

运行日志的保留时长，与请求日志是**两套独立设置**。详见[运行日志](/observability/runtime-logs)。

## 云同步

选择同步方式、连接凭据、绑定远端位置，并手动**备份到云端**或**从云端恢复**。恢复会用远端快照整份覆盖本机的供应商、模型与绑定，覆盖后无法撤销；快照里没有的逻辑模型保持不动。详见[配置云同步](/observability/cloud-sync)。

![OSW「设置 → 云同步」卡片：选择同步方式、连接凭据、绑定远端，以及备份到云端 / 从云端恢复两个手动动作。](/screenshots/zh-CN/light/settings-cloud-sync.png)

直达 **GitHub 仓库**与 **Discord 社区**，并展示一张**贡献者头像墙**（数据来自 GitHub 公开 API，出于限流考虑缓存一小时；拿不到时只显示入口，不影响跳转）。外链一律用系统默认浏览器打开。
