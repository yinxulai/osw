# 配置云同步

**配置云同步**把你的配置放进**你自己的**第三方云存储，在新机器上拉一次就能接着用。当前支持的承载方式只有 **GitHub Gist**。

<Callout title="不需要账号，不需要我们的服务器" type="info">
OSW 不引入账号体系，也不中转你的数据。流量是**本机直连所选后端**（Gist 走 `api.github.com`），我们不参与、不知道你同步了什么。
</Callout>

## 同步什么

| 包含 | 不包含 |
| --- | --- |
| 供应商与上游模型（**含各供应商的 API Key**） | 应用设置（监听地址、出站代理、界面偏好） |
| 逻辑模型（ID、说明、启用状态）与顺序 | 请求记录、用量统计与观测数据 |
| 逻辑模型到上游模型的绑定（优先级、启用状态） | —— |

<Callout title="设置故意不同步" type="note">
设置是本机环境的属性，把它同步到另一台机器等于替那台机器做决定。
</Callout>

## 换台机器就能用

因为包含各供应商的 API Key，所以拉取后不需要重新填密钥——否则「能接着用」只成立一半。

## 只编码，不加密

<Callout title="base64 不是加密" type="warning">
快照会做一次 base64 编码再落盘，**只是让远处那个文件不一眼可读**。拿到文件的人解一下就能还原全部内容，包括 API Key。请把 Gist 设为私密，并只用只勾 `gist` 权限的细粒度 PAT。
</Callout>

## 使用方式

在**设置 → 同步**里操作：

![OSW「设置 → 云同步」卡片：选择同步方式、连接凭据、绑定远端，以及备份到云端 / 从云端恢复两个手动动作。](/screenshots/zh-CN/light/settings-cloud-sync.png)

1. **签发凭据**：在 GitHub 上自建一个**只勾 `gist` 权限**的细粒度 PAT，粘进来。凭据可保存、清除、校验。
2. **绑定远端**（可选）：粘贴 Gist 地址，或留空让首次上传自动新建一个。
3. **上传 / 拉取**：都是**手动触发的一次动作**。

<Callout title="没有自动同步" type="info">
不做自动 / 定时 / 后台同步，也不做冲突检测与合并。你看到的就是你要做的：一次上传或一次拉取。
</Callout>

## 承载方式可换

Gist 只是第一种后端。接口按可插拔设计，每种后端只需要两个槽位：**凭据**与**远端句柄**（Gist 是「令牌 + Gist id」，将来 WebDAV 会是「密码 + 目录」）。换后端时，远端绑定与时间戳会一起清掉，但旧的凭据按类型保留，换回来还在。

<Callout title="只支持按名字存取单个对象" type="note">
承载方式必须能按名字读 / 写一个文件；只支持「整库覆盖」的存储不适合这套接口。
</Callout>

---

同步的是配置，不是你的数据去向。哪些东西会离开这台机器，见[本地优先与密钥](/observability/privacy)。
