# 运行日志

**运行日志**记的是**服务自己**在做什么，而不是你的请求——启动与停止、监听端口变更、配置保存、路由版本发布、内部错误与警告。

## 与请求记录的区别

| | 运行日志 | 请求记录 |
| --- | --- | --- |
| 记录对象 | 服务自身 | 经过的**用户请求** |
| 关心的问题 | 服务有没有正常工作 | 这条请求为什么失败 |
| 典型内容 | 启动、配置、内部错误 | 分发、尝试、耗时、上游错误 |

<Callout title="两套日志不混用" type="info">
运行日志服务于排障，字段是请求 ID、耗时、错误码；统计事件服务于产品决策，必须匿名、低基数。两套东西的要求正好相反，所以分开。
</Callout>

## 常见用途

- 启动失败：端口被占用、数据目录不可写。
- 配置异常：云同步冲突、密钥解密失败。
- 路由问题：某次发布是否成功、是否有回滚。

## 保留

运行日志的保留时长在**设置 → 数据 → 日志保留**里调整。它跟请求日志的保留策略是**两套独立设置**。
