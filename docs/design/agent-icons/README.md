## Notes

- Files are byte-for-byte copies of what the site serves; only the file names
  were normalized. Each SVG keeps its original `viewBox="0 0 24 24"`.
- `pi.svg`, `opencode.svg`, `cursor-cli.svg`, `copilot-cli.svg` and `goose.svg`
  use `fill="currentColor"`, so they inherit the surrounding text color. The
  rest carry their own brand colors/gradients.
- `deepseek-harness.svg` is the same asset the site uses for the DeepSeek
  provider icon.
- **Crush has no SVG on the site** — only a 128×124 PNG, so it is not
  scalability-clean. Source an official vector elsewhere if you need one.
